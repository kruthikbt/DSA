##  Complexity First

Before focusing heavily on solving problems, I'm learning to understand the efficiency of algorithms.

### Time Complexity

```text
O(1)       → Constant
O(log n)   → Logarithmic
O(n)       → Linear
O(n log n) → Linearithmic
O(n²)      → Quadratic
O(2ⁿ)      → Exponential
O(n!)      → Factorial
```

### Example

```c
for (int i = 0; i < n; i++)
{
    printf("%d ", arr[i]);
}
```

**Time Complexity:** `O(n)`
